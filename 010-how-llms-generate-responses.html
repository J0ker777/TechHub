1. Що таке LLM

LLM — Large Language Model, або велика мовна модель.

До цього класу належать GPT, Claude, Gemini, Llama та багато інших моделей.

Головна задача мовної моделі:

3. Що таке токен

Токен — це невелика частина тексту.

Токеном може бути:

  • слово;
  • частина слова;
  • знак пунктуації;
  • число;
  • пробіл або його частина;
  • комбінація символів.

5. Token ID — ще не «значення» слова

Може виникнути логічне питання.

Якщо:

то звідки модель розуміє, що REST пов'язаний з API, HTTP та вебсервісами?

Тут з'являється ще один важливий механізм — embeddings.

Token ID перетворюється на набір чисел — вектор.

Умовно:

Реальні вектори мають багато вимірів.

У процесі навчання модель формує такі числові представлення, які допомагають їй працювати зі зв'язками та закономірностями між токенами.

06

6. Контекст — що модель бачить прямо зараз

Тепер найцікавіше.

Уявімо діалог:

User:
Мене звати Олексій.

Assistant:
Приємно познайомитися!

User:
Як мене звати?

Модель може відповісти:

Олексій.

Здається, ніби вона запам'ятала ім'я.

Але на базовому рівні механіка інша.

Під час наступного запиту модель може отримати контекст діалогу приблизно такого виду:

User: Мене звати Олексій.
Assistant: Приємно познайомитися!
User: Як мене звати?

Тобто модель не обов'язково «згадує» попередню фразу так, як це робить людина.

Вона бачить її в поточному контексті.

07

7. Що таке context window

У кожної LLM є обмеження на кількість інформації, яку вона може обробити в одному контексті.

Це називається:

context window — контекстне вікно.

У ньому можуть знаходитися:

System instructions
        +
історія діалогу
        +
повідомлення користувача
        +
документи
        +
результати роботи інструментів
        +
інший переданий контекст

Усе це врешті займає токени.

Умовно:

Тому фраза:

↳
«AI пам'ятає нашу розмову»

часто технічно означає:

↳
моделі передали потрібну частину попередньої розмови в контексті.

У сучасних AI-системах також можуть існувати окремі механізми довготривалої пам'яті, але це вже надбудова навколо самої LLM.

10. Виходить, модель просто вгадує наступне слово?

І так, і ні.

На фундаментальному рівні — вона справді прогнозує наступний токен.

Але слово «вгадує» може створити неправильне враження.

Сучасна LLM має мільярди параметрів і під час навчання засвоює величезну кількість статистичних закономірностей:

мову
структуру тексту
зв'язки між поняттями
шаблони міркувань
структуру програмного коду
фактичні закономірності з навчальних даних

Тому прогноз:

next token

виконується на основі дуже складного представлення всього попереднього контексту.

Саме тому з простого механізму:

predict next token

може виникнути:

стаття
програма

діалог

11. Чому модель іноді відповідає неправильно

Тепер стає зрозумілим один із головних недоліків LLM.

Модель оптимізована не на правило:

говорити тільки перевірену істину

а передусім на:

генерувати правдоподібне продовження

Наприклад, ми питаємо про неіснуючу технологію:

Розкажи про протокол SuperFastAPI 7.0.

Якщо модель не розпізнає проблему, вона може почати будувати правдоподібну відповідь:

Структура тексту може виглядати абсолютно нормально.

А інформація при цьому може бути вигаданою.

Це одна з причин появи того, що називають:

hallucinations — галюцинації LLM.

16. Найцікавіший парадокс LLM

Уся складність сучасних мовних моделей у результаті зводиться до дуже простої задачі:

↳
Який токен має бути наступним?

Але якщо:

  • модель достатньо велика;
  • навчальних даних достатньо;
  • архітектура достатньо потужна;
  • контекст достатньо хороший;

то з багаторазового передбачення наступного токена виникає поведінка, яка зовні може нагадувати розуміння та міркування.

Саме це і робить сучасні LLM настільки цікавими.

17

Словник термінів простими словами

  • LLM — мовна модель, яка продовжує текст на основі вивчених закономірностей.
  • Token — невеликий фрагмент тексту: слово, частина слова, знак або пробіл.
  • Tokenizer розбиває текст на токени й перетворює їх на числові ID.
  • Token ID — номер токена у словнику; сам по собі він не містить значення слова.
  • Embedding — набір чисел, яким модель представляє властивості токена.
  • Context — інструкції, повідомлення, документи та вже згенерований текст, які модель бачить зараз.
  • Context window — максимальний обсяг токенів, які модель може врахувати за один раз.
  • Transformer обробляє контекст; attention визначає важливі для поточного кроку частини.
  • Model parameters — налаштовані під час навчання числа, у яких закодовані закономірності.
  • Inference — використання навченої моделі для генерації відповіді.
  • Probability distribution — оцінки можливих наступних токенів.
  • Temperature керує випадковістю вибору токена.
  • Hallucination — правдоподібна, але неправильна відповідь без надійного джерела.
  • RAG / tools дають моделі актуальні дані з документів, API або бази.
18

👶 Якщо зовсім просто

LLM пише відповідь по одному фрагменту. Вона читає контекст, оцінює наступні токени, вибирає один, додає його до контексту й повторює цикл.

Модель не дістає готове речення з внутрішньої енциклопедії. Її параметри зберігають закономірності з багатьох прикладів. Тому відповідь може бути переконливою, але неправильною.

Для актуальних даних застосунок додає документи чи викликає інструмент. Модель пояснює отримані факти людською мовою, а якість залежить від контексту, джерел, інструкцій і перевірки.

У своїй основі це величезна математична модель, навчена передбачати продовження послідовності токенів.
